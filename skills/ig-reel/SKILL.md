# ig-reel — طراحی ریلز

یک ایده را به ریلزی تبدیل می‌کند که تا آخر دیده شود. دو ابزار این پوشه واقعاً اجرا می‌شوند؛
استفاده‌شان کن، قلاب را چشمی قضاوت نکن و طول را حدس نزن.

```bash
python hookscore.py hooks.txt              # رتبه‌بندی قلاب‌ها (هر خط یکی)
python hookscore.py --hook "یک جمله"
python beats.py script.txt --target 30     # بیت‌شیت پیش از ضبط
```

## پیش از نوشتن

1. `ig-setup/page.py where` و خواندن `page.md`: مخاطب، لحن، چهره (دارد/ندارد)، دعوت اصلی،
   خطوط قرمز. فیلم‌نامه‌ای که با لحن صاحب پیج نخواند بی‌فایده است، چون باید بلند گفته شود.
2. `hooks.json` همین پوشه: ۲۴ فرمول با الگو، نمونه، متن روی صفحه، کاربرد و دامش. نمونه‌ها
   عمداً از موضوع‌های مختلف‌اند؛ تو نسخهٔ مخصوص همین پیج را می‌سازی.
3. اگر `swipe.md` در پوشهٔ پیج هست (`ig-viral` می‌سازد)، بخوانش. شواهد خود همین حوزه است و از
   پیش‌فرض‌های این فایل مهم‌تر است.
4. اگر ایده لاغر است، پرش نکن. یک سؤال یک‌جا بپرس: چه اتفاقی افتاد، برای چه کسی، و چه
   هزینه یا نتیجه‌ای داشت. ریلز یک چیز مشخص و راست لازم دارد.

## شکل ریلز

```
۰:۰۰ – ۰:۰۲   قلاب      ادعا. جملهٔ گفتاری و متن روی صفحه جدا. فریم اول حرکت یا متن دارد.
۰:۰۲ – ۰:۰۷   اهمیت     چرا برای بیننده مهم است. یک جمله.
۰:۰۷ – ...    بدنه       هر بیت یک حرف، و تصویر هر بیت عوض می‌شود.
۳ ثانیهٔ آخر  نتیجه      قول قلاب را عمل کن، بعد یک دعوت.
جملهٔ آخر     حلقه       یک کلمه از قلاب را تکرار کن تا دیدن دوباره روان باشد.
```

طول: ۱۵ تا ۴۵ ثانیه محدودهٔ کاری است.

## روند

1. **سه قلاب، نه یکی.** سه فرمول متفاوت که واقعاً به ایده می‌خورند؛ برای هر کدام جملهٔ گفتاری
   و متن روی صفحه (حداکثر ۶ کلمه).
2. **امتیاز.** سه جملهٔ گفتاری را در یک فایل بگذار و `hookscore.py` را اجرا کن. رتبه‌بندی را
   نشان بده. اگر بهترین زیر ۵۰ است، هنوز قلاب نداری.
3. **فیلم‌نامه** روی قلاب برنده: محاوره، جمله‌های کوتاه، همان‌طور که صاحب پیج حرف می‌زند.
4. **زمان‌بندی.** `beats.py script.txt --target <طول>`. هر هشدار را درست کن و دوباره اجرا کن.
5. **انسانی‌سازی.** از `ig-human` رد کن.
6. **فهرست نما.** برای هر بیت بنویس تصویر چیست. اگر پیج بدون چهره است، از این‌ها بساز:
   ضبط صفحهٔ گوشی یا کامپیوتر (نشان دادن خود ابزار)، دست‌ها و میز کار، فضای واقعی (مغازه،
   کارگاه)، متن روی تصویر. چهره وقتی لازم است که اعتماد مهم‌ترین چیز است؛ اگر کاربر
   نمی‌خواهد، اصرار نکن.
7. **متن روی صفحه** جدا: هر کارت حداکثر ۶ کلمه، کارت قلاب از فریم اول. زیرنویس بدنه را
   بگذار؛ بیشتر آدم‌ها اول بی‌صدا می‌بینند.

## خروجی در پوشهٔ محتوا

پوشه را با `ig-setup/page.py item --type reel --title "..."` بساز. بعد:

- `script.md`: قلاب‌ها با امتیاز، فیلم‌نامه، بیت‌شیت، فهرست نما، متن روی صفحه با زمان،
  پیشنهاد صدا (نوع حس، نه آهنگ مشخص؛ صدا را داخل اینستاگرام از کتابخانهٔ خودش بگذارد).
- `spec.json` با `"type": "reel"`: اسلاید اول `reel-cover` (کاور)، و اگر ویدیوی متنی
  می‌سازیم، برای هر بیت یک `reel-frame` با `dur` (ثانیه، از بیت‌شیت).
- `caption.txt` (روش در `ig-caption`).

ساخت تصویرها و ویدیو:

```bash
python <اسکیل‌ها>/ig-create/render.py <محتوا>/spec.json --page <پیج> --out <محتوا>/slides
python <اسکیل‌ها>/ig-create/video.py <محتوا>/spec.json --frames <محتوا>/slides --out <محتوا>/reel.mp4 --skip-cover --motion
```

ویدیوی متنی برای آموزش‌های کوتاه، فهرست‌ها و «یک نکته» خوب کار می‌کند. برای داستان و
اعتمادسازی، صدای واقعی صاحب پیج (حتی بدون چهره) خیلی بهتر است: فیلم‌نامه را بخواند، و فایل
صدا را با `--audio` روی همان فریم‌ها بگذار (زمان فریم‌ها را با بیت‌شیت صدای واقعی تنظیم کن).

**منطقهٔ امن:** render.py خودش رعایت می‌کند؛ اگر کاربر ویدیوی خودش را می‌سازد بگو: متن
بالای ۲۳۰ پیکسل، پایین ۱۴۴۰ پیکسل، و ۲۳۰ پیکسل سمت راست (ستون دکمه‌ها) نباشد. قلاب هیچ‌وقت
جای کپشن (پایین تصویر) نیست.

## جمع‌بندی برای کاربر

```
ریلز آماده
قلاب:        #۵ فشرده‌سازی زمان، امتیاز ۸۶ (قوی)
طول:         ۲۸ ثانیه، ۹ بیت
متن روی صفحه: ۶ کارت
انسانی‌ساز:   ۴ اصلاح، امتیاز انسانی ۸۱
فایل‌ها:      script.md، cover، reel.mp4 (یا: فیلم‌نامه برای ضبط)
```

بعد `ig-publish` برای پیش‌نمایش و تأیید.

## قانون‌ها

- **یک ریلز، یک حرف.** اگر فیلم‌نامه دو حرف دارد، دو ریلز است. بگو.
- **عدد به‌جای صفت.** اگر عدد لازم است و نداری، `{{عدد شما}}` بگذار و علامت بزن؛ هرگز نساز.
- **مقدمه ممنوع.** بدون سلام، بدون «توی این ویدیو»، بدون معرفی.
- **یک دعوت در آخر**، همان دعوت اصلی `page.md`.
- **هیچ نتیجه، مشتری یا درآمد ساختگی** به اسم صاحب پیج، حتی به‌عنوان جای‌نگهدار.
- **هیچ‌وقت منتشر نکن.** تأیید و انتشار با `ig-publish` و خود صاحب پیج است.
