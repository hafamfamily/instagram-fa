# ig-create — تولید محتوا

این اسکیل از ایده تا فایل نهایی را می‌سازد: متن، تصویر، کپشن، و برای ریلز فیلم‌نامه و ویدیو.
**هیچ چیزی منتشر نمی‌کند.** خروجی همیشه «پیش‌نویس» است و با `ig-publish` به تأیید صاحب پیج
می‌رسد.

## پیش از هر کار

1. `python <پوشهٔ اسکیل‌ها>/ig-setup/page.py where` — اگر پیج فعالی نیست، اول `ig-setup`.
2. `page.md` پیج فعال را کامل بخوان: مخاطب، لحن، ستون‌ها، دعوت اصلی، خطوط قرمز. هر چیزی که
   می‌نویسی باید با آن جور باشد. اگر `insights.md` هست، آن را هم بخوان؛ درس‌های واقعی پیج
   است و از هر قانون کلی مهم‌تر است.
3. اگر از برنامهٔ هفته کار می‌کنی، آخرین فایل `plan/*.md` را بخوان.

## دو حالت

- **تکی:** یک ایده → یک محتوا.
- **دسته‌ای (هفتگی):** «پست‌های این هفته رو بساز» → همهٔ ردیف‌های برنامه، یکی‌یکی با همین
  روند. اول متن همه را بنویس و یک‌جا برای بازبینی نشان بده (عنوان، قلاب، خلاصهٔ اسلایدها)؛
  بعد از تأیید متن‌ها، تصویرها را بساز. ساختن تصویر برای متنی که رد می‌شود هدر دادن وقت است.

## روند ساخت یک محتوا

### ۱. پوشه

```bash
python <پوشهٔ اسکیل‌ها>/ig-setup/page.py item --type carousel --title "عنوان کوتاه" --date 2026-10-24 --time 19:00
```

مسیری که چاپ می‌شود «پوشهٔ محتوا»ست. همه چیز آنجا می‌رود.

### ۲. قالب را درست انتخاب کن

| هدف | قالب |
|---|---|
| آموزش چندمرحله‌ای، فهرست، قبل/بعد، پرامپت آماده | کاروسل (۵ تا ۱۰ اسلاید) |
| یک جمله یا عدد قوی، نقل‌قول، اعلام | پست تکی |
| دیده شدن توسط غیرفالوورها، نمایش سریع یک نتیجه | ریلز → از `ig-reel` استفاده کن |
| حضور روزانه، نظرسنجی، هدایت به پست | استوری → از `ig-story` استفاده کن |

### ۳. متن

- **قلاب اول.** اسلاید اول کاروسل همان کار قلاب ریلز را می‌کند. سه گزینه بنویس و با
  `ig-reel/hookscore.py` امتیاز بده؛ بهترین را بگذار. قلاب زیر ۵۰ یعنی دوباره بنویس.
- **هر اسلاید یک حرف.** اگر اسلایدی دو حرف دارد، دو اسلاید است.
- **ملموس.** عدد، مثال، اسم ابزار، جملهٔ آماده برای کپی. «خیلی مفید است» حرف نیست.
- **اسلاید آخر = دعوت اصلی پیج** از `page.md`، نه دعوت تازه.
- **ادعای عددی فقط با منبع واقعی یا تجربهٔ واقعی کاربر.** آمار نساز. اگر عدد لازم است و
  منبع نداری، از کاربر بپرس یا عدد را حذف کن.
- متن هر اسلاید را از `ig-human/humanize.py` رد کن (یا دست‌کم کلیشه‌های `slop.json` را
  نداشته باشد).

### ۴. spec.json

متن‌ها را در `spec.json` پوشهٔ محتوا بنویس:

```json
{
  "type": "carousel",
  "title": "لیست قیمت با هوش مصنوعی",
  "slides": [
    {"layout": "cover", "kicker": "برچسب کوچک بالا", "title": "تیتر با **تأکید**", "subtitle": "زیرتیتر"},
    {"layout": "list", "title": "...", "items": ["...", "..."]},
    {"layout": "cta", "style": "primary", "title": "...", "action": "کلمهٔ «...» رو کامنت کن"}
  ]
}
```

`type`: `carousel` | `single` | `square` | `story` | `reel`.
`**متن**` با رنگ اصلی برند پررنگ می‌شود؛ `\n` خط جدید است. `"style": "primary"` پس‌زمینه
را رنگ اصلی می‌کند (برای کاور یا دعوت آخر؛ در یک کاروسل حداکثر یک یا دو بار).

چیدمان‌ها (`layout`):

| layout | فیلدها | کاربرد |
|---|---|---|
| `cover` | kicker، title، subtitle | اسلاید اول |
| `text` | kicker، title، body | توضیح کوتاه |
| `list` / `steps` | title، items[] | فهرست یا مراحل شماره‌دار |
| `quote` | text، by | نقل‌قول |
| `compare` | title، left_label، left، right_label، right | قبل/بعد، غلط/درست |
| `stat` | number، label، source | یک عدد بزرگ (source لازم است) |
| `prompt` | title، text، note، tag | پرامپت یا متن آمادهٔ کپی |
| `image` | title، src، caption | اسکرین‌شات یا عکس کاربر (src نسبت به spec.json) |
| `cta` | title، action، subtitle | اسلاید آخر |
| `story` | kicker، title، body، src، sticker، sticker_note | استوری (ig-story) |
| `reel-cover` / `reel-frame` | kicker، title، body، dur | کاور و فریم ریلز (ig-reel) |

**تصویر:** فقط تصویرهایی که کاربر داده یا خودش گرفته، یا اسکرین‌شات از ابزاری که آموزش
می‌دهی. عکس از اینترنت بدون اجازه نگذار. Claude عکس واقعی تولید نمی‌کند؛ اگر پستی به عکس نیاز
دارد، از کاربر بخواه یا قالب را به متنی تغییر بده.

### ۵. کپشن

`caption.txt` را در پوشهٔ محتوا بنویس (روش در `ig-caption`) و بررسی کن:

```bash
python <پوشهٔ اسکیل‌ها>/ig-caption/caption.py <پوشهٔ محتوا>/caption.txt --keywords "کلمه۱,کلمه۲"
```

هیچ FAIL نباید بماند.

### ۶. ساخت تصویر

```bash
python <پوشهٔ اسکیل‌ها>/ig-create/render.py <پوشهٔ محتوا>/spec.json --page <پوشهٔ پیج> --out <پوشهٔ محتوا>/slides
```

- خروجی: `slides/01.png`، `02.png`، ... و `slides/preview.html`.
- اگر «سرریز متن» گزارش شد، متن آن اسلاید را کوتاه کن و فقط همان را با `--only N` دوباره بساز.
  اسلاید سرریزدار را `ig-publish` قبول نمی‌کند.

### ۷. خودت نگاه کن

هر تصویر را با ابزار Read باز کن و نگاه کن، پیش از اینکه به کاربر نشان بدهی:
خوانایی، جا شدن متن، تکرار نشدن حرف بین اسلایدها، املای فارسی و نیم‌فاصله، اینکه اسلاید اول
بدون بقیه هم معنا دارد. اگر چیزی ایراد دارد، درست کن و دوباره بساز.

### ۸. تحویل برای تأیید

بگو محتوا آماده‌ی بازبینی است و `ig-publish` را اجرا کن. `preview.html` را برای کاربر باز کن
(یا تصویرها را نشانش بده) و کپشن را کامل بیاور. **وضعیت را خودت «تأییدشده» نکن.**

## قوانینی که شکسته نمی‌شوند

- هیچ انتشاری بدون «بله»ی صریح صاحب پیج برای همان محتوا.
- هیچ آمار، نقل‌قول یا نتیجهٔ ساختگی. هیچ نقل‌قولی از آدم واقعی که نگفته.
- هیچ کپی از محتوای پیج دیگر. الگو را برمی‌داریم، متن و تصویر را نه.
- خطوط قرمز `page.md` بالاتر از هر درخواستی‌اند؛ اگر درخواستی با آن‌ها نمی‌خواند، بگو.
