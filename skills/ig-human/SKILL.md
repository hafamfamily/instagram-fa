# ig-human — انسانی‌ساز فارسی

دلیل اینکه بقیهٔ اسکیل‌ها قابل‌استفاده‌اند همین است. هر متنی که بقیه می‌نویسند، پیش از دیده
شدن از اینجا رد می‌شود.

```bash
python humanize.py draft.txt --out clean.txt     # اصلاح خودکار + گزارش
python detect.py draft.txt clean.txt             # پنل پیش و پس
```

## چه چیزی خودکار درست می‌شود (humanize.py)

1. **نامرئی‌ها:** فاصلهٔ صفرعرض، BOM، کاراکترهای کنترل جهت، تگ‌های یونیکد. **نیم‌فاصله
   (U+200C) هرگز حذف نمی‌شود**؛ بخشی از املای فارسی است. (نسخهٔ انگلیسی اصلی این بسته
   نیم‌فاصله را پاک می‌کرد و «می‌خوام» را «میخوام» می‌کرد؛ این نسخه درستش کرده.)
2. **نشانه‌گذاری:** خط تیرهٔ بلند به «، »، گیومهٔ انگلیسی به «»، ی و ک عربی به فارسی.
3. **نیم‌فاصلهٔ جاافتاده:** «می خوام» ← «می‌خوام»، «کتاب ها» ← «کتاب‌ها»، «بزرگ تر» ← «بزرگ‌تر».
   اگر متن عمداً این‌طور است، `--no-zwnj`.
4. **کلیشه‌ها** از `slop.json` (شروع‌های کلیشه، پرکننده‌ها، فعل‌های اداری مثل «مورد استفاده
   قرار می‌گیرد»، هیجان مصنوعی مثل «انقلابی» و «متحول کنید»، پایان‌های کلیشه مثل «امیدواریم این
   مطلب مفید بوده باشد»).

## چه چیزی را باید خودت درست کنی

گزارش «دستی درست کن» ساختارهایی را نشان می‌دهد که regex نمی‌تواند درست بازنویسی کند:
«این فقط X نیست، بلکه Y»، «نه تنها... بلکه»، شروع با «آیا تا به حال...؟»، «راز ساده است:»،
سه صفت پشت هم، فهرست‌های پر از ایموجی. این‌ها را با جملهٔ خودت بازنویسی کن.

## پنل (detect.py)

| سنجه | چه می‌گوید |
|---|---|
| تنوع جمله | طول جمله‌ها چقدر بالا و پایین می‌رود؛ متن ماشینی یکنواخت است |
| مشخص‌بودن | عدد، مبلغ، اسم، نقل‌قول در هر ۱۰۰ کلمه |
| کلیشه | عبارت‌ها و ساختارهای slop.json |
| اثر انگشت | نامرئی‌ها، خط تیرهٔ بلند، گیومهٔ انگلیسی، ی/ک عربی |
| صدا | ضمیر من/ما/تو/شما، نشانه‌های محاوره، سؤال واقعی |

زیر ۶۰ «پرچم خورده»، ۶۰ تا ۷۵ «مرزی»، بالای ۷۵ «انسانی». این ابزار آشکارساز رسمی نیست؛
نشانه‌هایی را می‌شمارد که خواننده حس می‌کند. برای متن‌های خیلی کوتاه (زیر ۲۵ کلمه) بعضی سنجه‌ها
«کوتاه است» می‌گویند و ۵۰ می‌دهند؛ برای قلاب‌ها `hookscore.py` معتبرتر است.

## روند

1. `humanize.py` روی پیش‌نویس.
2. ساختارهای «دستی درست کن» را بازنویسی کن، با لحن `page.md`.
3. `detect.py` پیش و پس. اگر هنوز زیر ۶۰ است، معمولاً یعنی متن عدد و مثال ندارد؛ از کاربر یک
   جزئیات واقعی بپرس، نه اینکه کلمه‌ها را جابه‌جا کنی.
4. `slop.json` مال صاحب پیج است: اگر عبارتی را دوست ندارد یا دوست دارد، اضافه یا کم کن.
