# راه‌اندازی انتشار خودکار (یک بار، حدود ۳۰ دقیقه)

انتشار خودکار از راه **API رسمی اینستاگرام** انجام می‌شود. این تنها راهی است که حساب را به خطر
نمی‌اندازد؛ ربات‌های مرورگری و سرویس‌های غیررسمی خلاف قوانین اینستاگرام‌اند و حساب را مسدود می‌کنند.

> نام منوها در پنل متا گاهی عوض می‌شود. اگر چیزی دقیقاً با این راهنما یکی نبود، دنبال نزدیک‌ترین
> گزینه بگرد یا از Claude بپرس. منبع: مستندات رسمی متا (Instagram Platform → Instagram API with
> Instagram Login).

## آنچه لازم است

1. **حساب اینستاگرام حرفه‌ای** (Business یا Creator). در اپ اینستاگرام: تنظیمات ← نوع حساب ←
   تغییر به حساب حرفه‌ای. رایگان است و صفحهٔ فیسبوک لازم ندارد.
2. **حساب فیسبوک** برای ورود به Meta for Developers.
3. **کامپیوتری که در ساعت انتشار روشن و به اینترنت وصل است**، با Python 3.9 یا بالاتر،
   `pip install pillow` و برای ویدیو ffmpeg (`winget install ffmpeg`).

**دربارهٔ ایران:** اینستاگرام و پنل متا در ایران فیلترند. هم ساخت اپ و هم هر بار انتشار به
اینترنت بدون محدودیت نیاز دارند؛ یعنی کامپیوتر در ساعت انتشار باید به فیلترشکن وصل باشد. این
که متا ساخت اپ از ایران را می‌پذیرد یا نه، از پیش معلوم نیست؛ اگر جایی متوقف شدی، همان خطا را
به Claude نشان بده.

## گام ۱: ساخت اپ

1. به developers.facebook.com برو و با فیسبوک وارد شو؛ اگر بار اول است، ثبت‌نام توسعه‌دهنده را
   کامل کن.
2. **My Apps ← Create App.** نوع اپ را **Business** انتخاب کن (اگر پرسید). یک نام بده، مثلاً
   `instagram-fa-mypage`.
3. در صفحهٔ اپ، محصول **Instagram** را اضافه کن و بخش **API setup with Instagram login**
   (یا «Instagram business login») را باز کن.

## گام ۲: دسترسی‌ها

در همان بخش، این دو دسترسی باید فعال باشند:

- `instagram_business_basic`
- `instagram_business_content_publish`

چون فقط حساب **خودت** را وصل می‌کنی، «Standard Access» کافی است و به گفتهٔ مستندات، Advanced Access
فقط برای حساب‌های دیگران لازم است.

## گام ۳: گرفتن توکن

1. در بخش **API setup with Instagram login**، حساب اینستاگرامت را اضافه کن (Add account) و با
   همان حساب وارد اینستاگرام شو و اجازه بده.
2. کنار نام حساب، **Generate token** را بزن و توکن را کپی کن.

توکنی که از این صفحه می‌گیری **بلندمدت (۶۰ روز)** است. لازم نیست هر دو ماه دوباره بگیری:
`publish.py` در هر اجرا اگر توکن قدیمی شده باشد خودش آن را تمدید می‌کند.

## گام ۴: وصل کردن به بسته (روی کامپیوتر خودت)

**توکن را در گفتگو با Claude نفرست.** توکن مثل رمز حساب است. یک پنجرهٔ ترمینال (در ویندوز: cmd)
باز کن و بزن:

```
python <پوشهٔ اسکیل‌ها>/ig-publish/ig_api.py login --page <پوشهٔ پیج>
```

توکن را paste کن (دیده نمی‌شود) و Enter. باید ببینی: «وصل شد: @نام‌حسابت». توکن فقط در
`<خانهٔ پیج‌ها>/.secrets/<نام پیج>.json` روی همین کامپیوتر می‌ماند.

بررسی:

```
python <پوشهٔ اسکیل‌ها>/ig-publish/ig_api.py status --page <پوشهٔ پیج>
```

## گام ۵: میزبانی فایل

API اینستاگرام فایل را از کامپیوترت برنمی‌دارد؛ فقط از یک **آدرس عمومی اینترنتی**. پیش‌فرض
**litterbox** است: رایگان، بی‌ثبت‌نام، و فایل بعد از ۲۴ ساعت خودش پاک می‌شود. اگر اینستاگرام
خطای «نتوانست فایل را بردارد» (کد 9004) داد، یکی از این‌ها را در `publish.json` پیج بگذار:

```json
"hosting": {"provider": "cloudinary", "cloud_name": "نام-ابر", "upload_preset": "نام-پریست"}
```

(cloudinary.com، پلن رایگان؛ در Settings ← Upload یک upload preset از نوع **Unsigned** بساز)

```json
"hosting": {"provider": "ftp", "host": "ftp.example.com", "user": "...", "dir": "/public_html/ig",
            "base_url": "https://example.com/ig", "tls": true}
```

(هاست خودت؛ رمز را با `ig_api.py secret ftp_password --page <پیج>` ذخیره کن.) هاست ایرانی
ممکن است برای سرورهای خارج از ایران در دسترس نباشد؛ اول با یک فایل امتحان کن.

## گام ۶: حالت و زمان‌بند

```
python publish.py mode --page <پیج> auto          # بدون پرسیدن (یا manual: با تأیید تو)
python publish.py publish <پوشهٔ یک محتوا> --dry-run   # آزمایش بدون ارسال
python publish.py schedule --apply                 # هر ۱۵ دقیقه محتوای رسیده منتشر شود
```

در ویندوز، `schedule --apply` یک کار در Task Scheduler به نام `instagram-fa` می‌سازد. کامپیوتر
باید در ساعت انتشار روشن، بیدار و (در ایران) به فیلترشکن وصل باشد؛ اگر نبود، محتوا در اولین
اجرای بعدی منتشر می‌شود. گزارش هر انتشار در `<پوشهٔ پیج>/publish.log` است.

حذف زمان‌بند: `python publish.py schedule --apply --remove`

## محدودیت‌های API (از مستندات متا)

- عکس فقط JPEG (بسته خودش تبدیل می‌کند)، حداکثر ۸ مگابایت، نسبت ۴:۵ تا ۱٫۹۱:۱ برای فید.
- ریلز ۳ ثانیه تا ۱۵ دقیقه؛ استوری ویدیویی ۳ تا ۶۰ ثانیه.
- کاروسل تا ۲۰ آیتم.
- حدود ۱۰۰ انتشار با API در هر ۲۴ ساعت (مستندات در یک جا ۵۰ هم گفته؛ برای یک پیج معمولی هیچ‌کدام
  مسئله نیست).
- **استیکرهای لینک، نظرسنجی و مکان در استوری با API منتشر نمی‌شوند.** استوری‌ای که جای استیکر
  دارد را دستی منتشر کن، یا در spec استیکر نگذار.
- موسیقی کتابخانهٔ اینستاگرام را API نمی‌گذارد؛ موسیقی را خود ویدیو باید داشته باشد.
